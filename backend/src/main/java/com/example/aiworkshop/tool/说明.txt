1、场景设计 sceneDesign
2、分镜设计 storyboardDesign

5、分镜图片提示词生成 keyframeDesign
6、生成每一个分镜的键帧图片 generateImage
7、图片质量检测（如果质量检测不通过，需要返回第6步重新生成） imageQualityDetection
8、视频提示词生成 videoDesign

10、视频质量检测（如果质量检测不通过，需要返回第9步重新生成） videoQualityDetection
11、视频背景音去除 removeAudio
12、生成镜头对应的音频 generateSpeech
13、音视频整合 mergeAudioVideo
14、开启下一循环
15、将循环生成的所有视频拼接得到完整视频 concatVideos
16、字幕生成 generateSubtitles
17、字幕烧录 burnSubtitles
18、得到最终完整的解说视频
这是主任务，提交成功后会使用uuid生成fatherTaskId，然后存在数据库中，由于解说词可能会比较长，不需要全存，存一两句话就行。
主任务中的子任务包括多个图片生成和视频生成任务，这些子任务也需要存入数据库，这些子任务会携带fatherTaskId与父任务进行关联。
子任务在前端也同样会显示，但是需要展示成下拉列表的形式，打开主任务的下拉列表，会按照执行顺序显示子任务，每个子任务可以单独下载。
所有的子任务都执行结束了，主任务状态变更，可以下载，子任务没有执行完，主任务显示正在执行。
