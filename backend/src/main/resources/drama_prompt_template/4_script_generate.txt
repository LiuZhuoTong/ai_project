【输出要求】

【JSON格式定义】
{
  "title": "剧集名称（如有）",
  "scenes": [
    {
      "scene_id": "场景编号/内外景/时间/地点",
      "characters": "角色A（身份说明）、角色B（身份说明）",

【字段说明】
- scene_id：格式为 {场景编号}/{内外景}/{时间}/{地点}，示例："1/内/夜/阴森客厅"
- characters：该场景出现的人物，格式如 "沈渊（穿越者主角）、黑衣人（神秘反派）"
- action：对人物动作、周围环境、角色表情的文本描述。示例："阴森的棺材内，躺在里面的沈渊猛地睁开双眼。他急促地喘息着，眼神中充满惊恐"
- dialogues：对话列表，每个对话包含角色、情绪、台词
