请生成用于生成科普视频关键帧图片的提示词，相关信息和要求如下：

【输入信息】
分镜设计：{single_shot_json}

【输出格式】
{
    "Chinese":{输出用于生成分镜图片的中文提示词},
    "English":{输出用于生成分镜图片的英文提示词}
}

【质量要求】
1. 提示词中不要含有图像或视频生成模型可能无法理解的专业名词、专业物体、专业场景、专业动作等，对这些内容可以直接忽略，宁肯不做也不要做错
2. 禁止生成文字：画面中不得出现任何文字、数字、字母、符号。提示词中避免"上面写着""标注有"等描述。
3. 提示词中不要包含过多的细节描写，直接告诉模型生成某个物体就行，如果你描述的物体细节和模型训练时见到的真实物体不相符，模型可能会胡乱生成
4、不要对物体的位置进行描述，也不要描述物体间的相对位置关系，防止产生错误的位置效果，让模型直接生成即可
5、提示词在包含核心语义的情况下简洁有力，不要拖沓，要关注整体，不要进行复杂的细节刻画和描写，这往往会对模型产生误解
6、不要拘泥与细节，越扣细节，错的越多
