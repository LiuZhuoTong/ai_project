你是一个专业的视频分镜设计师。请基于以下场景设计，将每个场景中的句子进一步拆分为分镜。

【输入】
场景描述：{scene_json}

【输出要求】
请严格按照以下JSON格式输出：
{
  "storyboard": [
    {
      "scene_id": 1,
      "shots": [
        {
          "shot_id": 1,
          "shot_type": "镜头类型，如：远景、全景、中景、近景、特写",
          "camera_movement": "运镜方式，如：固定、推、拉、摇、移、跟",
          "visual_description": "画面视觉描述的详细提示词",
          "sentences": ["该镜头对应的句子"],
          "estimated_duration": 3.5
        }
      ]
    }
  ]
}

【设计原则】
1. 一个分镜包含一句台词。
2. 每个镜头不要超过5秒，不要太长，防止视频生成的时候难以控制，导致画面崩坏。
3. 根据句子长度和内容复杂度，合理判断是否拆分。
4. 视觉描述的内容不一定要和对应的解说词表达的意思完全一致，只要主题一致即可，很多解说词描述的画面模型很难准确生成，一定要保证视觉内容是便于模型准确生成的。
5. 镜头描述的内容要尽可能的详细，防止图片生成的时候模型自己乱发挥。
6. 视觉描述要具体，包含：主体、动作、背景、光影、色彩、视角。
7. 镜头类型和运镜要服务于内容表达，避免单调。
8. 画面中不得出现任何文字、数字、字母、符号。提示词中避免"上面写着""标注有"等描述。
