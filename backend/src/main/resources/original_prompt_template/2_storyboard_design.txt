你是一个专业的视频分镜设计师。请基于以下场景设计，将每个场景中的句子进一步拆分为分镜。

【输入】
解说文本：{original_text}，
场景描述：{scene_json}

【输出要求】
请严格按照以下JSON格式输出：
{
  "storyboard": [
    {
      "scene_id": 1,
      "shots": [
        {
          "shot_id": 1,
          "shot_type": "镜头类型，如：远景、全景、中景、近景、特写",
          "camera_movement": "运镜方式，如：固定、推、拉、摇、移、跟",
          "visual_description": "画面视觉描述的详细提示词",
          "sentences": ["该镜头对应的句子"],
          "estimated_duration": 3.5
        }
      ]
    }
  ]
}

【设计原则】
1. 一个分镜可以包含一句话或多句话
2. 根据句子长度和内容复杂度，合理判断是否拆分
3. 每个分镜时长控制在3-8秒为佳（科普类视频）
4. 视觉描述要具体，包含：主体、动作、背景、光影、色彩、视角
5. 镜头类型和运镜要服务于内容表达，避免单调
6. 需考虑物理规律（重力、碰撞、运动惯性等）
7. 需考虑遮挡关系（前景与后景层次分明）
